# AgentSync

Claude と GPT が同居する、LINE 風のグループチャットです。Mac のデスクトップアプリとして、個人で使うために作っています。

- Claude と GPT に、個別に話しかけることも、両方へ同時に送ることもできます
- 「対話モード」ボタンを押すと、その時点の会話の続きから Claude と GPT が交互に話し続けます。もう一度押すと止まります
- コーディングモードでは、プロジェクトのフォルダを指定すると、普段の Claude Code / Codex と同じように作業できます。片方が実装し、もう片方がレビューするループも回せます

## 状態

開発中です。個別送信・同時送信・対話モード・会話の保存と一覧・コーディング会話（承認カード、実装＋レビュー）・連携（MCP）の管理・使用量の表示まで使えます。構想は [PLAN/PLAN.md](PLAN/PLAN.md)、画面案は [PLAN/screens/](PLAN/screens/index.html) にあります。

## 仕組み

API キーは使いません。手元に入れた **Claude Code CLI** と **Codex CLI** を、アプリが裏で呼び出します。

- 各 CLI には、自分のアカウントでログインしておく必要があります
- 使用量は、それぞれのプランの使用枠から消費されます
- このアプリの会話履歴は手元のファイルに保存されます。応答生成時には会話内容を各サービスへ送信します。各サービス側の保存の扱いは、それぞれの設定とポリシーに従います

## 必要なもの

- macOS
- Node.js
- Claude Code の CLI（`claude`）。Claude のプランでログイン済みであること
- [Codex CLI](https://github.com/openai/codex)（`codex`）。ChatGPT のプランでログイン済みであること

## アプリとして使う

```sh
npm install
npm run install:app   # AgentSync.app を作り、アプリケーションフォルダに入れる
```

- 自分の Mac でビルドしたアプリなので、そのまま起動できます（Apple の公証は受けていません）
- 会話は `~/Library/Application Support/AgentSync/conversations/` に、会話ごとの小さな JSON ファイルとして保存されます。ファイルは自分だけが読める権限で作ります
- 返事を待つあいだ、吹き出しに各 AI がいま何をしているか（考え中・ウェブを検索中・入力中）と、経過した秒数が出ます。「全員」に送ると、2 人は同時に考え、同時に答えます
- 入力欄の上の「対話モード」を押すと、その時点の会話の続きから Claude と GPT が交互に話し続けます。最後に話した AI ではない方から始まり、止めるまで続きます（そのぶん使用枠も使います）。止めるときは、もう一度押すか「停止」を押します。対話中に送った発言は「割り込み」として次の話者に渡され、対話はそのまま続きます
- ヘッダーの「Claude」「GPT」を押すと、それぞれのモデルと考える深さ（effort）を選べます。モデルの一覧は各 CLI から取るので、CLI が新しいモデルに対応すれば、そのまま選べます。Claude は一覧にないモデル ID も入力できます。effort は浅くするほど速く答えます。「自動」は各 CLI の設定のままです。選んだものは次の返事から使われ、新しい会話にも引き継がれます（`settings.json` に保存）
- 返事にマウスを乗せると「コピー」ボタンが出ます。コードブロックには、言語名とコピーボタンが付きます。上にスクロールして読んでいる間に返事が増えたら、「最新へ」ボタンで戻れます
- メニューの「ファイル」に、対話モードの切り替え（⇧⌘D）と、返事を止める（⌘.）があります。返事の途中で Esc を押しても止まります
- 入力欄で ↑ を押すと、前に送った発言を呼び出せます（続けて押すとさらに前へ、↓ で新しい方へ。最後まで戻ると書きかけの文に戻ります）
- Claude Code や Codex が見つからないときは、アプリのメニューの「AgentSync > CLI の場所…」で実行ファイルを指定できます
- 会話の名前は、最初のメッセージから自動で付きます。変えるには、サイドバーの会話の「…」メニュー（右クリックでも開きます）の「名前を変更」を選ぶか、会話をダブルクリックするか、ヘッダーの名前をクリックします。Enter で決定、Escape で取り消しです
- 同じメニューの「削除…」で会話を削除すると、このファイルが消えます。Claude Code と Codex 側の履歴は残ります

### コーディング会話

- サイドバー上部の「チャット / コード」でコーディング会話の一覧に切り替え、「新しい会話…」（⇧⌘N）でプロジェクトのフォルダを選ぶと、そのフォルダで Claude と GPT が作業する会話ができます。ヘッダーにフォルダ名とブランチ名が出ます
- 宛先を Claude か GPT にすると、その 1 人がファイルを変更し、コマンドを実行できます。「全員」宛てと対話モードでは、2 人とも読み取り専用です（変更できるのは、いつも 1 人だけ）
- 入力欄の「承認制 / auto」で、変更の前に確認するかを切り替えます。承認制では、ファイルの編集とコマンドの実行の前に承認カード（許可・今回は全部許可・拒否）が出ます。読み取りと検索は確認なしで進みます。auto は各 CLI の auto モードに任せます（作業ブランチで使ってください）
- 吹き出しに作業ログ（読んだファイル・検索・編集・実行したコマンド）が出ます
- 「実装＋レビュー」ボタンで役割を選びます: Claude が実装 → GPT がレビュー、または GPT が実装 → Claude がレビュー。選んだ時点では何も始まりません。何も選ばなければ、宛先の 1 人だけが変更できるふだんの動きです
- 実装役を選んだあとに依頼を送ると、実装役が作業し、アプリが `git diff` をレビュー役に渡し、レビュー役が確かめる、を繰り返します。レビュー役が `APPROVED` と返すか、3 往復で止まります。ボタンをもう一度押すと途中で止められます
- 役割は会話ごとに保存されます。同じ役割をもう一度選ぶと解除です

### 2画面表示

- 右上の画面アイコンで、今のスレッドを左右に並べて表示できます。同じスレッドでも、左右それぞれ別の位置までスクロールできます
- 各画面の上部で別のスレッドを選べます。サイドバーから選ぶと、最後にクリックした画面が切り替わります
- 入力欄と書きかけの文章は左右別々です。同じスレッドを開いている場合、送信したメッセージと返事は両方に反映されます
- 中央の境界をドラッグすると幅を調整できます。境界にフォーカスを合わせて左右の矢印キーでも調整できます
- 停止・対話モードのショートカットは選択中の画面に作用します。画面アイコンをもう一度押すと、選択中の画面を残して1画面に戻ります。非表示にした会話の処理は継続します

### 会話の一覧

- サイドバー上部の「チャット / コード」で、ふつうの会話とコーディング会話の一覧を切り替えます
- 会話の「…」メニュー（または右クリック）の「ピン留め」で、一覧のいちばん上に固定できます

### 連携と使用量

- Claude と GPT は、それぞれの CLI につないだ連携（Notion・Google Drive などの MCP サーバー）とウェブ検索を、チャットでもコーディングでも使えます。読み取りはそのまま進み、作成・変更・削除は承認カードで確認します
- サイドバーの「連携」で、各 CLI の連携の一覧・追加（名前と URL）・削除・ログイン（Codex）ができます。claude.ai のコネクタは claude.ai の設定で管理します
- サイドバーの「使用量」で、各プランの 5 時間枠と週の使用率を確認できます（Claude Code の `/usage` と Codex の使用量を読むだけで、使用枠は使いません）

## 開発

```sh
npm install
npm run dev        # 開発モードで起動（初回は Electron 本体をダウンロードします）
npm test           # 単体テスト
npm run typecheck  # 型チェック
npm run build      # 本番用にビルド（out/ に出力）
npm run dist       # AgentSync.app を作る（release/ に出力）
npm run icon       # build/icon.svg からアプリのアイコン（build/icon.png）を作り直す（案は PLAN/icon/ にあります）
```

- Node.js は 22.12 以降が対象です（推奨は 24 LTS）
- npm 10.9 系では、新しいパッケージを追加するときに依存解決のエラーが出ることがあります。その場合は npm 11 以降を使ってください（`package-lock.json` からのインストールは問題ありません）
- 開発中（`npm run dev`）の会話は、アプリとは別の `~/Library/Application Support/AgentSync-dev/` に保存されます

### 実際の CLI を使った確認

```sh
npm run test:e2e
```

Claude Code CLI と Codex CLI を実際に呼び出して、同時送信と、相手の発言が文脈として届くこと、アプリを起動し直しても各 AI が会話の続きを覚えていることを確かめます。少しだけ使用枠を消費します（既定では小さいモデルを使います。`AGENTSYNC_CLAUDE_MODEL` と `AGENTSYNC_GPT_MODEL` で変えられます）。

### 開発用の環境変数

| 変数 | 内容 |
|---|---|
| `AGENTSYNC_CLAUDE_MODEL` / `AGENTSYNC_GPT_MODEL` | 新しい会話で使うモデル（例: `haiku`、`gpt-6-luna`）。ヘッダーのメニューで選んだものより優先する |
| `AGENTSYNC_CLAUDE_PATH` / `AGENTSYNC_CODEX_PATH` | CLI の場所を直接指定する（「CLI の場所…」で選んだものより優先する） |
| `AGENTSYNC_PROJECT_FOLDER=<フォルダ>` | 「コーディング会話…」でフォルダを選ぶ代わりに、このフォルダを使う（自動テスト用） |
| `AGENTSYNC_SELFTEST=<出力先.png>` | 画面からメッセージを 1 回送り、ウィンドウの画像を保存して終了する（パッケージ化したアプリでは無効）。データは使い捨てのフォルダに置く |
| `AGENTSYNC_SELFTEST_DATA=<フォルダ>` | セルフテストのデータを置くフォルダ。同じフォルダでもう一度動かすと、保存した会話の続きから試せる |

### アプリ更新時の権限

- アプリ更新の追加許可は既定で無効です。必要なプロジェクトの `.agentsync.local.json` に `{"allowAppUpdate":true}` を置くと、そのプロジェクトのautoで有効になります。このファイルはGitの対象外です
- GPT は `/Applications/AgentSync.app` だけを追加の書き込み先にします。Claude は `ditto <ビルド済み.app> /Applications/AgentSync.app` または `rsync -a --delete <ビルド済み.app>/ /Applications/AgentSync.app/` の単独コマンドを追加の確認なしで許可します。コピー元はそのプロジェクトの `release/mac-arm64/AgentSync.app` または `release/mac/AgentSync.app` に限定します
- 他のコマンドとの連結、別アプリへの書き込み、ネットワーク接続の許可は増やしません。承認制・読み取り専用には適用しません
- `npm run dist` は `node_modules/electron/dist` の Electron を再利用します。依存関係の初回インストールにはダウンロードが必要です
